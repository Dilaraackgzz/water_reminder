# Android Release Keystore Setup Instructions

## ⚠️ IMPORTANT: Security Notice

Your release keystore is EXTREMELY IMPORTANT:
- **NEVER** commit it to git (already in .gitignore)
- **BACKUP** it in a secure location (USB drive, password manager, encrypted cloud)
- If you lose it, you **CANNOT** update your app on Play Store ever again!
- Store the passwords securely (password manager recommended)

---

## 🔧 Step 1: Generate Release Keystore

Open terminal in your project root and run:

```bash
cd android

keytool -genkey -v -keystore release-keystore.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias aqualert-release
```

### You'll be prompted for information:

1. **Enter keystore password:** Choose a strong password (save it!)
2. **Re-enter keystore password:** Confirm the password
3. **Enter key password:** Can be same as keystore password (recommended)
4. **What is your first and last name?** Your name or company name
5. **What is the name of your organizational unit?** (Can press Enter to skip)
6. **What is the name of your organization?** Your company/personal name
7. **What is the name of your City or Locality?** Your city
8. **What is the name of your State or Province?** Your state/province
9. **What is the two-letter country code?** TR (for Turkey) or your country
10. **Is this correct?** Type `yes`

---

## 📝 Step 2: Create key.properties File

Copy the example file and fill in your values:

```bash
cd android
cp key.properties.example key.properties
```

Now edit `android/key.properties` with your actual values:

```properties
storePassword=YOUR_ACTUAL_STORE_PASSWORD
keyPassword=YOUR_ACTUAL_KEY_PASSWORD
keyAlias=aqualert-release
storeFile=../release-keystore.jks
```

**Replace:**
- `YOUR_ACTUAL_STORE_PASSWORD` → The keystore password you created in Step 1
- `YOUR_ACTUAL_KEY_PASSWORD` → The key password you created in Step 1

---

## 🔐 Step 3: Get SHA-1 Certificate Fingerprint

You need this for Firebase and Google Play:

```bash
cd android

keytool -list -v -keystore release-keystore.jks -alias aqualert-release
```

**Save these values:**
- SHA-1: `XX:XX:XX:...` (needed for Firebase/Google Sign-In)
- SHA-256: `XX:XX:XX:...` (needed for some APIs)

---

## 🔥 Step 4: Update Firebase with SHA-1

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select your project: **aqualert-7850d**
3. Click ⚙️ (Settings) → Project settings
4. Scroll to "Your apps" section
5. Click on your Android app (com.dlrackgz.aqualert)
6. Click "Add fingerprint"
7. Paste your **SHA-1** from Step 3
8. Click "Save"
9. Download the new `google-services.json`
10. Replace `android/app/google-services.json` with the new file

---

## ✅ Step 5: Verify Configuration

Check that everything is set up correctly:

```bash
# 1. Verify keystore exists
ls android/release-keystore.jks
# Should show: android/release-keystore.jks

# 2. Verify key.properties exists
ls android/key.properties
# Should show: android/key.properties

# 3. Verify they're NOT tracked by git
git status android/release-keystore.jks android/key.properties
# Should show: "did not match any files"
```

## 🏗️ Step 6: Test Release Build

Try building a release version:

```bash
# Clean previous builds
flutter clean

# Build release APK
flutter build apk --release

# Or build App Bundle (recommended for Play Store)
flutter build appbundle --release
```

If successful, you'll see:
- APK: `build/app/outputs/flutter-apk/app-release.apk`
- AAB: `build/app/outputs/bundle/release/app-release.aab`

## 💾 BACKUP CHECKLIST

After generating your keystore, **IMMEDIATELY** backup these files:

- [ ] `android/release-keystore.jks` → Backup to 3+ locations
- [ ] `android/key.properties` → Save passwords in password manager
- [ ] SHA-1 and SHA-256 fingerprints → Save in secure note

**Recommended backup locations:**
1. Encrypted USB drive
2. Password manager (1Password, LastPass, Bitwarden)
3. Encrypted cloud storage (Google Drive with encryption, Dropbox)
4. Print QR code and store in safe (for extreme security)

---

## 🚨 What If You Lose Your Keystore?

If you lose your release keystore:
- You **CANNOT** update your existing app on Play Store
- You'll have to publish a completely NEW app (new package name)
- All your existing users, reviews, and rankings are **LOST**

**This is why backups are critical!**

---

## 📱 Play Store Console Setup

When uploading to Play Store:

1. Go to [Play Console](https://play.google.com/console)
2. Select your app
3. Go to "Release" → "Setup" → "App signing"
4. Choose "Use Google Play App Signing" (recommended)
5. Upload your app bundle (.aab file)
6. Google will manage the signing key

**Note:** With Google Play App Signing, your release keystore is used to sign the bundle you upload, then Google re-signs it with their key for distribution.

## 🔍 Troubleshooting

**Error: "Keystore was tampered with, or password was incorrect"**
- You entered the wrong password
- Check your key.properties file for typos

**Error: "Failed to read key from keystore"**
- The keyAlias might be wrong
- Verify with: `keytool -list -v -keystore release-keystore.jks`

**Error: "java.io.FileNotFoundException: ../release-keystore.jks"**
- Keystore file doesn't exist in android/ folder
- Check the storeFile path in key.properties
