# Android Release Keystore Kurulum Talimatları

## ⚠️ ÖNEMLİ: Güvenlik Uyarısı

Release keystore dosyanız SON DERECE ÖNEMLİDİR:
- **ASLA** git'e commit etmeyin (zaten .gitignore'da)
- Güvenli bir yere **YEDEK ALIN** (USB disk, şifre yöneticisi, şifreli bulut)
- Kaybederseniz, uygulamanızı Play Store'da **ASLA GÜNCELLEYEMEZSINIZ!**
- Şifreleri güvenli bir yerde saklayın (şifre yöneticisi önerilir)

---

## 🔧 Adım 1: Release Keystore Oluşturma

Proje ana dizininde terminal açın ve şu komutları çalıştırın:

```bash
cd android

keytool -genkey -v -keystore release-keystore.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias aqualert-release
```

### Size şu bilgiler sorulacak:

1. **Enter keystore password:** Güçlü bir şifre seçin (kaydedin!)
2. **Re-enter keystore password:** Şifreyi onaylayın
3. **Enter key password:** Keystore şifresiyle aynı olabilir (önerilir)
4. **What is your first and last name?** Adınız veya şirket adınız
5. **What is the name of your organizational unit?** (Enter'a basarak geçebilirsiniz)
6. **What is the name of your organization?** Şirket/kişisel adınız
7. **What is the name of your City or Locality?** Şehriniz
8. **What is the name of your State or Province?** İl/bölgeniz
9. **What is the two-letter country code?** TR (Türkiye için)
10. **Is this correct?** `yes` yazın

## 📝 Adım 2: key.properties Dosyası Oluşturma

Örnek dosyayı kopyalayın ve bilgilerinizi girin:

```bash
cd android
cp key.properties.example key.properties
```

Şimdi `android/key.properties` dosyasını gerçek değerlerinizle düzenleyin:

```properties
storePassword=GERCEK_STORE_SIFRENIZ
keyPassword=GERCEK_KEY_SIFRENIZ
keyAlias=aqualert-release
storeFile=../release-keystore.jks
```

**Değiştirin:**
- `GERCEK_STORE_SIFRENIZ` → Adım 1'de oluşturduğunuz keystore şifresi
- `GERCEK_KEY_SIFRENIZ` → Adım 1'de oluşturduğunuz key şifresi

---

## 🔐 Adım 3: SHA-1 Sertifika Parmak İzi Alma

Firebase ve Google Play için buna ihtiyacınız var:

```bash
cd android

keytool -list -v -keystore release-keystore.jks -alias aqualert-release
```

**Bu değerleri kaydedin:**
- SHA-1: `XX:XX:XX:...` (Firebase/Google Sign-In için gerekli)
- SHA-256: `XX:XX:XX:...` (bazı API'lar için gerekli)

---

## 🔥 Adım 4: Firebase'i SHA-1 ile Güncelleme

1. [Firebase Console](https://console.firebase.google.com/) adresine gidin
2. Projenizi seçin: **aqualert-7850d**
3. ⚙️ (Ayarlar) → Project settings'e tıklayın
4. "Your apps" bölümüne kaydırın
5. Android uygulamanıza tıklayın (com.dlrackgz.aqualert)
6. "Add fingerprint" butonuna tıklayın
7. Adım 3'ten aldığınız **SHA-1**'i yapıştırın
8. "Save" butonuna tıklayın
9. Yeni `google-services.json` dosyasını indirin
10. `android/app/google-services.json` dosyasını yenisiyle değiştirin

## ✅ Adım 5: Yapılandırmayı Doğrulama

Her şeyin doğru kurulduğunu kontrol edin:

```bash
# 1. Keystore'un var olduğunu doğrulayın
ls android/release-keystore.jks
# Göstermeli: android/release-keystore.jks

# 2. key.properties'in var olduğunu doğrulayın
ls android/key.properties
# Göstermeli: android/key.properties

# 3. Git tarafından takip EDİLMEDİĞİNİ doğrulayın
git status android/release-keystore.jks android/key.properties
# Göstermeli: "did not match any files"
```

## 🏗️ Adım 6: Release Build Testi

Release versiyonu build etmeyi deneyin:

```bash
# Önceki build'leri temizleyin
flutter clean

# Release APK oluşturun
flutter build apk --release

# Veya App Bundle oluşturun (Play Store için önerilir)
flutter build appbundle --release
```

Başarılı olursa şunları göreceksiniz:
- APK: `build/app/outputs/flutter-apk/app-release.apk`
- AAB: `build/app/outputs/bundle/release/app-release.aab`

## 💾 YEDEKLEME KONTROL LİSTESİ

Keystore'unuzu oluşturduktan sonra **HEMEN** şu dosyaları yedekleyin:

- [ ] `android/release-keystore.jks` → 3+ farklı yere yedekleyin
- [ ] `android/key.properties` → Şifreleri şifre yöneticisine kaydedin
- [ ] SHA-1 ve SHA-256 parmak izleri → Güvenli bir nota kaydedin

**Önerilen yedekleme konumları:**
1. Şifreli USB disk
2. Şifre yöneticisi (1Password, LastPass, Bitwarden)
3. Şifreli bulut depolama (şifreleme ile Google Drive, Dropbox)
4. QR kod çıktısı alıp kasada saklayın (ekstra güvenlik için)

## 📱 Play Store Console Kurulumu

Play Store'a yüklerken:

1. [Play Console](https://play.google.com/console) adresine gidin
2. Uygulamanızı seçin
3. "Release" → "Setup" → "App signing" bölümüne gidin
4. "Use Google Play App Signing" seçeneğini seçin (önerilir)
5. App bundle (.aab) dosyanızı yükleyin
6. Google imzalama anahtarını yönetecektir

**Not:** Google Play App Signing ile, yüklediğiniz bundle'ı imzalamak için release keystore'unuz kullanılır, ardından Google dağıtım için kendi anahtarıyla yeniden imzalar.

## 🔍 Sorun Giderme

**Hata: "Keystore was tampered with, or password was incorrect"**
- Yanlış şifre girdiniz
- key.properties dosyanızda yazım hatası olup olmadığını kontrol edin

**Hata: "Failed to read key from keystore"**
- keyAlias yanlış olabilir
- Şununla doğrulayın: `keytool -list -v -keystore release-keystore.jks`

**Hata: "java.io.FileNotFoundException: ../release-keystore.jks"**
- Keystore dosyası android/ klasöründe yok
- key.properties dosyasındaki storeFile yolunu kontrol edin
