# Firebase Setup Instructions

## ⚠️ IMPORTANT: Firebase Configuration Security

The `firebase_options.dart` file has been removed from version control for security reasons.
This file contains sensitive API keys and should NEVER be committed to git.

## 🔧 Setting Up Firebase on Your Machine

### Step 1: Install FlutterFire CLI (if not already installed)

```bash
dart pub global activate flutterfire_cli
```

### Step 2: Generate firebase_options.dart

```bash
# Make sure you're in the project root directory
cd /Users/dilaraacikgoz/AndroidStudioProjects/water_reminder

# Run FlutterFire configure
flutterfire configure
```

### Step 3: Select Your Project

When prompted:
1. Select existing project: **aqualert-7850d**
2. Select platforms: **Android, iOS** (use space to select, enter to confirm)
3. This will create `lib/firebase_options.dart` automatically

### Step 4: Verify File Was Created

```bash
ls lib/firebase_options.dart
# Should show: lib/firebase_options.dart
```

## ✅ File is Already in .gitignore

The file is already listed in `.gitignore`, so it won't be accidentally committed:

```
# Firebase & Secrets
firebase_options.dart
```

## 🔄 For Team Members

Each team member needs to:
1. Have Firebase CLI access to the `aqualert-7850d` project
2. Run `flutterfire configure` on their machine
3. Select the same Firebase project
